🎯 HOW IT WORKS:

  1. User visits:           https://your-project.vercel.app/
  2. Frontend serves:       React app (static files)
  3. User submits YouTube:  POST /api/generate
  4. Vercel routes to:      backend/api/index.py (serverless)
  5. Backend processes:     Transcript → Groq LLM → Notes
  6. Returns JSON:          Notes + PDF links
  7. Frontend displays:     Beautiful results!
